# Number Guessing Game

## Project Overview

Number Guessing Game is a desktop application developed using Python and Tkinter. The program randomly generates a number between 1 and 100, and the player must guess it. The application provides hints until the correct number is guessed.

---

## Objective

The objective of this project is to practice:

- Python Fundamentals
- Functions
- Conditional Statements
- Random Module
- Exception Handling
- Tkinter GUI Development
- Event Handling

---

## Features

- Random number generation
- Guess validation
- Too High / Too Low hints
- Attempt counter
- New Game option
- Exit button
- User-friendly GUI
- Error handling

---

## Technologies Used

- Python 3.x
- Tkinter
- Random Module

# SentimentAI — Hugging Face NLP Analyzer

An interactive sentiment analysis web application built using
Hugging Face Transformers and Gradio.

## Project Overview

This project demonstrates how to integrate a pre-trained
Natural Language Processing model from Hugging Face into
an interactive web application.

The application accepts user text and predicts whether
the sentiment is positive or negative along with the
model confidence score.

## Features

- Pre-trained Hugging Face NLP model
- Sentiment classification
- Confidence score
- Interactive Gradio interface
- Example inputs
- Simple Python-based inference
- Ready for Hugging Face Spaces deployment

## Technologies

- Python
- Hugging Face Transformers
- PyTorch
- Gradio
- Kaggle
- Hugging Face Hub
